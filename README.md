# مصاريفي — Masareefi 💰

تطبيق أندرويد ذكي لتتبع المصاريف والدخل يفهم **العامية المصرية والعربية الفصحى** بالصوت والكتابة، مع دعم مزدوج للذكاء الاصطناعي (Google Gemini) والتحليل المحلي بدون إنترنت (Offline).

---

## 🌟 أهم المميزات المنجزة

1. **إدخال ذكي بالصوت والكتابة (عامية وفصحى)**:
   - "ضيفلي دخل 5000 مرتب"
   - "صرفت 50 قهوة"
   - "سجل مصروف 120 سوبرماركت"
   - "قبضت الجمعية 4000"
   - "دفعت فاتورة الكهربا 350 جنيه"
   - "صرفت خمسين جنيه بنزين"

2. **دعم ثنائي للذكاء الاصطناعي (أونلاين + أوفلاين)**:
   - **مفتاح ذكاء Google Gemini**: إمكانية إدخال المفتاح وفحصه وتحديد النموذج (`gemini-2.5-flash`).
   - **محلل محلي فائق الذكاء أوفلاين**: يعمل فوراً حتى بدون إنترنت أو بدون مفتاح، يفهم كلمات الدخل والمصروف وتصنيفاتها والأرقام المحكية والمكتوبة.

3. **لوحة مالية متكاملة (Dashboard)**:
   - **كارت المتبقي (الرصيد الصافي)**: كارت بارز يُظهر الفائض أو العجز المالي ونسبة المصروفات من الدخل بدقة.
   - **كرتين صغيرين**:
     - كارت إجمالي **الدخل** الأخضر مع عدد العمليات.
     - كارت إجمالي **المنصرف** الوردي مع عدد العمليات.

4. **رسم بياني دائري تفاعلي (Donut / Pie Chart)**:
   - رسم دائري أنيق للدخل والمنصرف مع نسبة مئوية وصافي الرصيد في المنتصف.

5. **تبويبين في أسفل الشاشة (دخل ومصاريف)**:
   - **تبويب الدخل**: سجل بكافة عمليات الدخل مع التصنيف والوقت وإمكانية الحذف.
   - **تبويب المصاريف**: سجل بكافة عمليات الصرف مع أيقونة التصنيف التلقائي والتفاصيل.

6. **تصميم عصري متطور**:
   - خط **Tajawal** العربي الفاخر بجميع أوزانه.
   - واجهة داكنة مريحة للعين مع دعم كامل للاتجاه من اليمين لليسار (RTL).
   - قاعدة بيانات SQLite محلية وسريعة باستخدام Android Room.
